PDF Studio — quick guide

Ctrl/⌘ OOpen PDF
Ctrl/⌘ SSave
Ctrl/⌘ Z / Ctrl/⌘ YUndo / Redo
Ctrl/⌘ FFind text
Ctrl/⌘ + / − / scrollZoom
V S T D H R WRead, Select, Text, Draw, Highlight, Rectangle, White-out
DeleteDelete the selected edit
Double-click textEdit text you added
EscFinish typing / deselect

Editing existing text: PDFs don't store editable paragraphs. To change printed text, use White-out to cover it, then add new text on top.

Forms: fillable fields appear in the Form tab of the sidebar. Click a field on the page in Read mode to jump to it.

Pages: drag thumbnails to reorder. Use Merge to append another PDF.

Markdown: .md files open in Preview. Switch to Split or Source to edit (Ctrl/⌘ E toggles), then save with Ctrl/⌘ S. To show pictures that use relative paths, open or drop the image files together with the .md file.

Everything runs locally in your browser. Your files never leave this computer.
